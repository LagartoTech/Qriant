# Contributing to Qriant

## Português

Contribuições são bem-vindas!

Antes de enviar mudanças:

1. Verifique se o projeto compila.
2. Mantenha o código simples e fácil de entender.
3. Evite adicionar dependências sem necessidade.
4. Explique claramente o que foi alterado.

Para mudanças maiores, abra uma issue antes de começar.

## English

Contributions are welcome!

Before submitting changes:

1. Make sure the project builds successfully.
2. Keep the code simple and easy to understand.
3. Avoid unnecessary dependencies.
4. Clearly explain what has changed.

For larger changes, please open an issue before getting started.
